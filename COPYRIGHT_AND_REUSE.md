# Rights and redistribution

The author may publish the original analysis scripts, supplementary scripts and aggregate numeric outputs subject to any applicable institutional and third-party rights. **This kit does not grant an open-source license or choose a license on the author's behalf.** The code and descriptive documentation should have their own stated reuse terms before a public repository deposit.

Respondent-level BHPS/UKHLS microdata from UK Data Service study 6614 are distributed under separate access and End User Licence requirements and are **not** included. Official questionnaire transcripts/PDFs are not redistributed; only bibliographic/page-reference metadata appear here. Users must obtain authorized access to the original data and documentation to re-estimate the models.

The replication archive is prepared for publication; it is not represented as already being available online or having a DOI. The paper can continue to say public deposit is forthcoming until a stable public location actually exists.
