# Financial Pessimism and the Timing of Saving

**Replication materials — Version 1.1.0**

This repository contains the replication code, aggregate empirical results, and supporting documentation for:

Hansak, Alexander (2026). *Financial Pessimism and the Timing of Saving.* Working paper, University of Graz.

The analysis uses the British Household Panel Survey (BHPS) and Understanding Society (UKHLS). It examines how the association between subjective financial expectations and household saving differs across observation horizons.
